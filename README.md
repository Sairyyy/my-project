# My Project

Це навчальний вебпроєкт, який містить базову структуру HTML-сторінки та файл стилів CSS. Проєкт створено для демонстрації навичок верстки та роботи з системами контролю версій.

## Встановлення

Клонуйте репозиторій на свій комп'ютер:

```bash
git clone https://github.com/Sairyvy/my-project.git
```
## Використання

Відкрийте файл `index.html` у браузері для перегляду сторінки.

## Структура проєкту

| Файл/Папка | Опис |
| :--- | :--- |
| `index.html` | Головна сторінка проєкту |
| `css/` | Папка зі стилями |
## Ліцензія
